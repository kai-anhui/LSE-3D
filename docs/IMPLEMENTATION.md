# 设计对应、实现假设与验收边界

依据：项目原始设计文档 v0.1，已逐节阅读。目录最初仅有此文档，没有可复用的模型实现。后续用户提供数据路径后，另阅读了标注目录 README 和点云选区代码以确定数据语义。

## 数据流与隔离

1. 一个 batch 包含一个完整输入场景块和 Q 条查询。场景编码只执行一次。点特征为 `[M,D]`；两级单元为 `[N1,D]`、`[N2,D]`。
2. 预处理仅使用几何/颜色，输出 point2unit、scan_idx `[K,N]`、edge_feat `[K,N,6]`、edge_valid `[K,N]` 与点到单元的插值邻域。四扫描为 Hilbert 正反向、Morton 正反向，反向重新计算边。
3. 文本编码 `[Q,L,D]`，三个独立 softmax 汇聚产生 q_id/q_anchor/q_scope `[Q,D]`。没有短语真值输入。
4. 上下文仅接收 z、q_id、q_anchor，全域递推。范围分支输入 z、c、q_scope，SSM 参数 Δ/B/C 仅由 z、q_scope 预测；当前写入 u 由 z、c、q_scope 预测。
5. `A=-exp(theta)`，Δ=softplus；`h=rho*exp(ΔA)*h_prev+Δ*B*u`，当前写入不乘 rho。rho=m*sigmoid(gate)。初始末层权重零、偏置 3，raw gate 初值约 0.952574。
6. 扫描逆置换后融合方向，两个尺度插值回点。身份头只看 c 和点特征；范围残差看 r/c/点特征。最终概率 sigmoid(identity+delta)。身份概率不硬阈值，不裁剪候选。
7. target、valid、parent_target、pairs 仅由损失/评价读取。已测试改变标签不改变模型输出，身份输出对范围特征梯度为 None。

## 按设计实现的监督与评价

- BCE 用 logits 以保持数值稳定，按正面积权重及有效域归一。Dice 对确认空目标关闭；无有效标注跳过。
- EQ 约束概率差；SUB/SUP/EDIT 对真实变化域比较带符号概率差；共同前景漂移不被共同背景稀释。
- 包含方向：SUB 惩罚 `relu(pb-pa)`，SUP 惩罚 `relu(pa-pb)`。OTHER/UNKNOWN 不启用成对项。
- 身份一致性要求共享载体且共享参照；父区域 BCE 使用独立 valid。
- 门监督要求单元全部点已知且正例占比不在 (0.1,0.9)，边必须几何有效并至少一端为目标。混合、未知及纯远背景边排除。
- 每个损失按适用项均值聚合并记录 count。门标签在 loss 内产生，不传入模型。
- 评价：权重 IoU、点级 IoU/Acc、DirIoU、EQCons、EQJoint、FalseChange、Drift-fg；full/local 分组，地点/父组宏平均和地点 bootstrap 函数。
- BF 使用调用者提供的参考表面图最短路径，不能把普通欧氏近邻距离伪装成表面测地距离。缺少参考网格时不在 CLI 结果中编造 BF。
- 固定阈值只在 val 校准并写回 checkpoint；测试前冻结。

## 文档未定处采用的显式假设

| 问题 | 当前处理 | 与原设计的关系 |
| --- | --- | --- |
| 场景范围 | 每个输入目录代表完整声明域；不按 GT 裁切；真实调试均匀抽取全场点 | 解决参考运行的资源问题，不声称保留全部密度；正式块需同时覆盖目标和参照 |
| 单元构建 | 体素邻接按法向和颜色区域生长，每组最多 8 体素；细单元质心限距图聚类为粗尺度，每组最多 8 单元 | 采用建议路线，最大组大小、阈值为工程补充；粗尺度不保证恰好 1/8 |
| 几何描述 | k=16 PCA 法向及线性度/平面度/散度，点 MLP 接坐标、法向、形状、高程、RGB | 编码器选型原文待定；不是 PTv3/稀疏 U-Net |
| 影像编码 | 可训练两层 CNN + 标定采样与置信度融合 | 是可运行参考模块，不是 DINOv2；未提供原始带位姿影像 |
| 文本编码 | UTF-8 字节、位置嵌入、两层 Transformer；或显式本地 HF 编码器 | 语言和预训练权重原文待定，字节方案支持中文输入但从零训练 |
| 上下文 SSM | 按文档递推公式实现选择性 SSM，各方向/尺度独立参数 | 不是官方完整 Mamba block；没有擅自声称与官方卷积/skip结构相同 |
| batching | batch=1 场景 + Q 查询，支持梯度累积；扫描算子另支持 valid padding | 使用文档允许的 batch=1 路径，尚无多场景 packed 高吞吐实现 |
| 扫描后端 | reference 循环、parallel 结合扫描、chunked 分块循环 | 三者同一公式；parallel O(N log N)，不是宣称线性工作量的融合内核 |
| 门附近可靠边 | 至少一端为明确目标的有效边 | 文档“目标邻近”未定，采取保守可核验定义 |
| 空目标 | 保留 BCE，Dice 关闭 | 采用文档建议 |
| 面积 | 没有网格时 w=1 | 只能解释为点级指标，不能宣称真实表面积权重效果 |
| 自动构造对 | 未启用 | 不违反人工核验要求；现有描述不自动推出 EQ/SUB/SUP/EDIT |
| 数据增强 | 可选共享旋转、缩放、抖动、丢点、影像缺失，几何与扫描重建 | 默认关闭便于排查；投影采样跟随原始点对应 |

## 已做验证

2026-11-18 本机运行：

- pytest：15 passed、1 skipped；跳过官方 mamba_ssm 数值对照，因为该库未安装。
- 三个 PyTorch 递推后端输出一致；并行与循环的梯度一致；rho=1 与独立公式手动递推一致。不能把此项替代成“已通过官方 Mamba 验证”。
- gate=0 阻断旧状态、padding 不更新状态、扫描逆排列、Hilbert 网格路径邻接、反向边符号正确。
- 无影像时项精确为零；有影像时图像编码器有梯度；门可靠正/负边梯度方向正确。
- 前后查询交换同时改关系方向，损失一致；空有效域返回可反传零损失。
- DirIoU 删除二者/额外新增一者=2/3；FalseChange=1/3；EQ 双空一致=1；无真值边界 BF 不适用。
- 单状态/仅范围/双状态无门消融可前向反向；相同 CPU 种子三步更新损失完全一致。
- 合成 500 步完整训练、验证定阈值、测试、无标签推理通过，三个核心合成指标为 1.0。仅作为过拟合验收。
- 长青全场 2048 点抽样、374 条未复核描述导入；GPU 3 步损失与梯度有限。因仅有已知正例，不用此结果声称真实精度。

## 未完成或需要外部条件的部分

1. **正式数据监督与评测**：需清理描述歧义、确认标注版本关系、标记可靠负例/争议域，并人工双人核验范围查询对。当前只有一个已标注地点，无法产生合规的独立地点验证/测试结果。
2. **预训练骨干**：PTv3/稀疏 U-Net、DINOv2 尚未集成；HF 文本适配接口已写但没有实际预训练权重运行验证。这些是文档的待选项，不能据此宣布达到论文预训练配置效果。
3. **大场景加速**：尚无 Triton 融合前后向、官方 Mamba CUDA 后端和多 GPU 训练。chunked 避免完整序列 h 堆叠，但 autograd 仍保存中间图，不保证百万点训练显存。生产规模应增加融合扫描/检查点并实测。
4. **B1/B2/B5/B6/B7**：外部基线源码/权重未提供；输出图裁剪、几何谓词、Transformer 门作用方式仍未最终定义。没有用不等价实现占位；不支持的 gate_mode 直接报错。内部消融没有完成参数量/预算公平匹配。
5. **完整论文实验**：多种子、多地点、门干预统计、网格 BF、真实推理延迟与峰值显存研究尚未完成。CLI 已提供基础评价，不填造论文结果表。

因此，当前交付可用于继续开发、真实数据规范化和小规模实验，不能描述为“所有研究里程碑 M0–M6 已全部完成”。

## 用户指定目录重构

已按用户要求将代码拆分为顶层 `data/`、`models/`、`utils/`、`engine/`、`tools/`。其中 Dataset、增强与 build_dataloader 分离，骨干与任务头分离，日志、checkpoint、随机种子、可视化分别归入工具模块。训练通过统一构建接口运行。实验配置迁移为 YAML，支持 `_base_` 相对路径继承，提供 `base.yaml` 和 `lse3d_exp01.yaml`。

旧 `lse3d/` 实现、JSON 实验配置和迁移辅助脚本已归档到 `outputs/legacy_structure/`，不再作为活动源码或入口。自动审批拒绝永久删除旧结构，采用可恢复归档完成整理。原 `artifacts/` 下的运行产物完整迁移至 `outputs/`；原始用户数据继续位于外部原路径，`datasets_raw/` 是预留目录，未复制或修改原始点云。

重构验证：18 passed、1 skipped；通过新 train/test/inference 入口完成训练更新、验证阈值校准、测试、无标签预测及 PLY 导出。原有 checkpoint 严格加载成功，重构前后 prob、id_logit、scope_delta 最大绝对差均为 0，记录于 `outputs/refactor_comparison.json`。
